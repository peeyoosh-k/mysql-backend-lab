# MySQL Backend Lab

My SQL practice repository: from basic queries to indexing, transactions and schema design, built as a foundation for backend engineering with Java.

## Contents
| Folder | Focus |
|---|---|
| 01-sql-basics | DDL, DML, SELECT, constraints |
| 02-functions-and-aggregates | Built-in functions, GROUP BY, HAVING |
| 03-joins-and-sets | All join types, UNION |
| 04-subqueries-and-cte | Subqueries, CTEs, recursive queries |
| 05-window-functions | RANK, LAG/LEAD, running totals |
| 06-indexes-and-performance | Indexes, EXPLAIN, optimization |
| 07-transactions-and-locking | ACID, isolation levels, deadlocks |
| 08-schema-design | ER diagrams, normalization |
| 09-views-procedures-triggers | Views, procedures, triggers |
| 10-security-and-administration | Users, backups, imports |
| 11-jdbc-with-java | Connecting Java to MySQL |
| 12-practice-problems | LeetCode / HackerRank SQL |
| projects | Complete database designs |

## Tech
MySQL 8.4 LTS, MySQL Workbench / DBeaver, Java 21 (JDBC), Git

## How to run
```
mysql -u <user> -p < path/to/file.sql
```
No passwords are stored in this repository.
